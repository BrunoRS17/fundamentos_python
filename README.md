# Fundamentos de Python 🐍

Este repositório reúne minhas resoluções de exercícios e atividades práticas como parte de um processo de **revisão e consolidação dos fundamentos da linguagem Python**.

Mais do que concluir exercícios, o objetivo é fortalecer o raciocínio lógico, compreender os conceitos em profundidade e desenvolver autonomia na resolução de problemas.

## 📚 Material de referência

As atividades seguem o livro **_Introdução à Programação com Python_**, de **Nilo Ney Coutinho Menezes**, **4ª edição**.

O repositório é um registro pessoal de estudos, sem vínculo com o autor ou a editora. O foco está nas minhas implementações, e não na reprodução integral dos enunciados ou do conteúdo do livro.

## 🎯 Objetivos

- Revisar conceitos fundamentais de Python e lógica de programação.
- Resolver exercícios de forma independente, do planejamento à implementação.
- Praticar a leitura, a escrita, a execução e a depuração de código.
- Identificar lacunas de conhecimento e acompanhar minha evolução.
- Consolidar uma base sólida para o desenvolvimento de software.

## 🧠 Política de uso de inteligência artificial

**Nenhuma ferramenta de IA será utilizada para escrever ou resolver os códigos dos exercícios deste repositório.** Isso inclui geração de soluções, sugestões automáticas de implementação e correções feitas por IA.

A IA pode ser valiosa para acelerar o desenvolvimento em outros contextos. Aqui, porém, **a prioridade é o aprendizado, não a velocidade de entrega**. O processo de pensar, experimentar, errar, investigar e corrigir faz parte do propósito do projeto.

## 🛠️ Como os exercícios serão realizados

1. Ler e compreender o conteúdo e o problema proposto.
2. Elaborar uma solução com raciocínio próprio.
3. Implementar a resolução utilizando Python.
4. Executar testes, identificar erros e realizar as correções necessárias.
5. Registrar e organizar as soluções para consulta e revisão futura.

O código poderá evoluir à medida que novos conceitos forem estudados, preservando o caráter autoral das resoluções.

## 📁 Organização

As resoluções serão organizadas progressivamente, seguindo os capítulos e os assuntos estudados no livro. A estrutura do repositório poderá ser ajustada conforme o avanço das atividades.

## ▶️ Execução

Para executar um exercício, tenha o **Python 3** instalado e utilize o terminal:

```bash
python caminho/para/o/exercicio.py
```

Em alguns sistemas, o comando pode ser `python3`.
